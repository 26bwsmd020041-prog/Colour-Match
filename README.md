# Colour Match

A simple, accessible single-page colour matching game.

Gameplay
- A target colour is shown at the bottom.
- You must pick the tile in the grid that exactly matches the target colour.
- Each correct pick increases the score and difficulty by enlarging the grid.
- A timer counts down; the game ends when time reaches zero.

Features
- Progressive difficulty (more tiles each level)
- Keyboard navigation (arrow keys + Enter)
- Color-blind pattern overlay toggle
- Sound toggle (simple beeps)
- High score persisted to localStorage

Files
- index.html
- styles.css
- script.js

How to run
1. Open `index.html` in a modern browser.
2. Press Start and pick the matching colour.

Deployment
This is a static site — you can enable GitHub Pages in repository settings to host the game.
